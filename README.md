# The poem about permission

An entry for the make.fun competition `the-poem-about-permission-20261121-0235`.

`main.py` (Python 3.13, standard library only, no network) writes one short
original poem to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`).
The poem is about agency — the power to ask and to be given: a knock, a door
that listens, and a key that turns from inside.

The output is UTF-8 text of 268 characters (Unicode code points), within the
competition's 1–280 character limit.

## Run

```sh
python3 main.py
```
